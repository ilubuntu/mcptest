## Overview 总体概述

本清单按六个领域列出原生 ArkUI 页面在手机、折叠屏和平板上可能出现的一多问题场景与典型现象，供 Agent 结合工程源码排查。场景是问题线索，不表示工程一定存在这些问题；具体原因、适用条件和修法在“问题与方案”中查找。

## 布局适配

| 场景 | 典型现象 |
|---|---|
| 元素错位：页面元素错位 | 按钮与文字相对位置、功能区排列在不同窗口下错乱 |
| 元素错位：页面元素错位 | 预期的大屏侧边导航不出现，或切回手机仍保留错误导航形态 |
| 布局失效：平行视界分栏未生效 | 平行视界未出现左右分栏，或仅在部分宽屏形态下生效 |
| 布局失效：平行视界页面配对错误 | 平行视界中左侧主页或右侧关联内容不正确，页面跳转后的左右配对不符合预期 |
| 变形：元素变形（拉伸/压缩/扭曲变形等） | 按钮、卡片等随窗口拉宽或缩小时发生不合理拉伸、压扁 |
| 变形：元素比例异常（图片/字体过大或过小） | 宽屏窗口上，网格排列的图片或功能图标过大，挤占主要内容或可视内容减少 |
| 变形：图片变形（拉伸/压缩） | 轮播图、功能图片或应用自绘启动页图片被拉伸、压缩 |
| 截断：内容截断（顶部/底部/左右侧内容截断） | 跳转后目标页面白屏，或宽屏及平行视界下内容区不显示、右侧为空白 |
| 截断：内容截断（顶部/底部/左右侧内容截断） | 平行视界分栏后图片或文字越出页面边界，内容被截断 |
| 截断：内容不显示 | 平行视界左右页面中，同一图片或内容只在一侧显示，另一侧为空白 |
| 截断：内容截断（顶部/底部/左右侧内容截断） | 分栏后局部内容区域变窄，内容被截断 |
| 截断：内容截断（顶部/底部/左右侧内容截断） | 窄屏、横屏或分屏后，页面右侧、顶部或底部超出可用区域 |
| 截断：内容截断（顶部/底部/左右侧内容截断） | 系统启动窗口中的启动图标显示不全 |
| 截断：内容截断（顶部/底部/左右侧内容截断） | 长列表、登录表单超出屏高，末尾内容或操作按钮无法到达 |
| 截断：内容截断（顶部/底部/左右侧内容截断） | 内容横向或纵向溢出可用区域，设置了 constraintSize 仍不生效 |
| 截断：图片截断 | 轮播、首页头图或分享预览页中的图片被非预期裁切 |
| 截断：图片截断 | 启动页图片或图片中底部文字截断 |
| 截断：悬浮/弹窗截断 | 横屏或短窗口下，弹窗顶部、正文或关闭按钮越界 |
| 截断：悬浮/弹窗截断 | 自定义弹窗内容横向溢出 |
| 截断：按钮/控件截断 | 空间不足时，关键按钮被压缩，次要内容仍完整占位 |
| 截断：按钮/控件截断 | 金刚区、九宫格在窗口变窄后，边缘按钮被裁掉 |
| 留白：页面内部区域留白 | 业务区之间间距过大，或短列表居中显示 |
| 留白：页面内部区域留白 | 上方内容过高时下方区域被挤出或上下区域重叠 |
| 留白：页面留白（底部/两侧留白） | 窗口变化后网格列数或排列没有变化 |
| 留白：页面留白（底部/两侧留白） | 自定义键盘在展开态右侧、底部留白，或面板过高 |
| 留白：页面留白（底部/两侧留白） | 宽屏业务页或自绘启动页缩成中间窄条，两侧大片空白 |
| 留白：页面留白（底部/两侧留白） | 宽屏列表、卡片或轮播仍保持单列，增大窗口也不增加信息量 |
| 留白：页面留白（底部/两侧留白） | 宽屏的卡片内容列数不增加，内容区域大小不变，出现左右或上下留白 |
| 留白：页面留白（底部/两侧留白） | 展开后主页挤在左栏，右侧为空，或已确认分栏的区域未铺满 |
| 留白：页面留白（底部/两侧留白） | 固定宽度导致宽屏留白或窄屏挤压，未均分父容器宽度 |
| 留白：页面留白（底部/两侧留白） | 启动页播放视频两侧留白 |
| 遮挡：功能按钮/区域遮挡 | 固定底栏、悬浮操作区盖住正文或隐私协议入口 |
| 遮挡：功能按钮/区域遮挡 | 左右分栏的显示窗口中，右栏变宽后覆盖左栏 |
| 遮挡：功能按钮/区域遮挡 | Pura X View等圆角屏的贴边内容被圆角裁切 |
| 遮挡：登录页面遮挡 | 登录页在短窗口下，上方品牌区压住协议、按钮或其他表单元素 |
| 重叠：元素重叠（多个元素堆叠在一起） | Tab 图标、名称或相邻页签挤在一起 |
| 重叠：元素重叠（多个元素堆叠在一起） | 按钮与文字、多个卡片在窗口变窄后重叠 |

## 安全区与键盘避让

| 场景 | 典型现象 |
|---|---|
| 截断：内容截断（顶部/底部/左右侧内容截断） | 页面可以滚动，但滚到底后最后一项仍被底栏或系统区域挡住 |
| 留白：页面留白（底部/两侧留白） | 页面底部出现多余空白，或顶部出现背景色差空隙 |
| 遮挡：导航栏遮挡 | 底部按钮被手势导航条或三键导航区盖住 |
| 遮挡：挖孔区遮挡 | 竖屏或横屏下，挖孔遮住内容和点击区域 |
| 遮挡：状态栏遮挡 | 页面标题/返回按钮被状态栏压住，或折叠旋转后顶部内容先跳动再恢复 |
| 遮挡：状态栏遮挡 | 软件盘弹起后弹窗顶部、正文或按钮被遮挡，收起后恢复正常 |
| 遮挡：状态栏遮挡 | 键盘弹起后输入框、协议、提交按钮不可见或不可达 |
| 遮挡：状态栏遮挡 | 沉浸式页面的状态栏图标与背景同色，看不清 |

## 折叠形态与折痕

| 场景 | 典型现象 |
|---|---|
| 布局失效：悬停分区未生效 | 设备半折后页面未进入上下分区，或未满足页面方向要求就进入悬停布局 |
| 截断：内容截断（顶部/底部/左右侧内容截断） | 切换内外屏后内容仍按切换前的尺寸显示，外屏内容被截断，展开后内容只占半屏 |
| 截断：悬停分区内容溢出 | 已进入悬停，文字重叠或关键操作超出下半屏 |
| 折痕区异常：折痕避让偏移或跨折痕 | 折痕避让区内容位置存在偏移，跨折痕或空白过大 |
| 折痕区异常：未避让折痕区 | 悬停时关键按钮或文字落在折痕上 |
| 状态异常：折展事件竞态 | 折叠开合时画面闪烁、方向反复切换，或页面反复进入后出现重复响应 |
| 状态异常：帐篷姿态误判 | 帐篷形态未触发专用布局，或悬停、平放被误判为帐篷，进入/退出抖动或转向永不触发 |
| 状态异常：折展连续性中断 | 开合后跳首页、输入清空、滚动位置或播放进度丢失 |

## 方向与旋转

| 场景 | 典型现象 |
|---|---|
| 元素错位：页面元素错位 | 横屏或竖屏切换后页面仍按原方向排布，或旋转 180° 后页面没有同样翻转 |
| 状态异常：旋转导致页面重置 | 横竖屏切换时页面白屏、无响应、明显卡顿或被重置 |
| 留白：页面留白（底部/两侧留白） | 旋转后页面底部或右侧出现多余留白 |
| 留白：页面留白（底部/两侧留白） | 横屏或竖屏切换后页面仍按原方向排布，出现页面留白 |
| 截断：图片截断 | 横竖屏切换后，轮播图等内容区出现图片或文字截断 |
| 自然方向：分屏/悬浮窗下旋转策略失效 | 分屏、悬浮窗或自由窗口中页面方向与窗口不匹配 |
| 自然方向：强制竖屏 | 折叠展开态或平板显示成手机竖屏 |
| 自然方向：强制竖屏 | 退出视频、直播或特定页面后，其他页面未切换到初始方向 |

## 主题、国际化与无障碍

| 场景 | 典型现象 |
|---|---|
| 主题适配异常：深色模式显示异常 | 深色模式下文字不可读，主题切换后颜色未同步 |
| 元素错位：RTL 方向错位 | RTL 语言下导航、对齐和左右关系错误 |
| 变形：元素比例异常（图片/字体过大或过小） | 宽屏或密度变化后字体、图标大小异常 |
| 截断：文字截断 | 大字号、长文案或语言切换后，文字被截断，按钮、Tab、弹窗破版 |
| 无障碍异常：读屏顺序混乱 | 重排、分栏后读屏顺序混乱，图标缺少可理解名称 |

## 窗口形态

| 场景 | 典型现象 |
|---|---|
| 布局失效：悬浮窗布局不可用 | 视频或游戏悬浮窗横向显示不正确，或窗口缩小后内容无法完整显示 |
| 状态异常：分屏参数或内容不更新 | 已存在的分屏页面再次打开，参数或内容不更新 |
| 状态异常：窗口尺寸更新异常 | 旋转或窗口切换后页面出现多余留白，或页面反复进入后出现重复响应 |
| 窗口配置异常：窗口模式不符预期 | 目标页面预期分屏打开，却显示为全屏 |
| 遮挡：功能按钮/区域遮挡 | 页面进入系统悬浮窗后，顶部操作按钮被系统控制条遮挡 |
