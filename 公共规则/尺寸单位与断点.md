## Overview 总体概述

用于核对“尺寸是什么单位、量的是哪里、属于哪个断点”。不维护具体机型尺寸，也不规定列数和导航。

适用范围：本知识库中的设备尺寸、预览基线及窗口／容器断点。
核验日期：2026-11-02。

## 1. 尺寸与单位

| 信息 | 单位或形式 | 含义 |
|---|---|---|
| 屏幕对角线 | 英寸 | 硬件屏幕的对角线长度，不是应用可用面积 |
| 屏幕分辨率 | `px` | 机型规格中对应屏幕的像素尺寸 |
| 运行态窗口尺寸 | 保留来源单位 | 当前应用窗口的宽高；不能与屏幕分辨率混用 |
| 布局逻辑尺寸 | `vp` | HarmonyOS 布局使用的逻辑尺寸 |
| 字体尺寸 | `fp` | HarmonyOS 字体尺寸单位，应考虑字体缩放 |
| HTML 预览尺寸 | CSS `px` | 高保真画布及缩放后的浏览器展示尺寸，不是设备物理分辨率 |
| 高宽比 | `h / w` | 同一窗口或容器、同一单位下的高度除以宽度，无单位 |

按“宽×高”记录，标明单位、方向，以及规格、实测或设计参考。方向变化后重新取值，不只改方向名称。

`window.getWindowProperties().windowRect` 的宽高为 px。其他接口或工具需核对单位，不能看到 width/height 就默认是 vp。字体缩放与显示缩放分别记录。

## 2. 分辨率不能直接代表窗口

屏幕分辨率、系统显示区域、应用窗口和内容容器是不同对象。分屏或自由窗口下，不能用整屏尺寸代替应用窗口；分栏内部使用所在栏的尺寸。实际占位和避让的计算见《一多适配总体原则》的空间分配说明。

## 3. px、vp 与预览尺寸的使用

### px 与 vp

优先使用工程对应的系统单位转换能力。不能统一按 `/3`、`/2.5` 换算，需采用当前环境的有效密度及正确上下文；硬件 PPI 不能代替有效显示密度。官方同时给出 px、vp 时保留原值及取整说明，不自行重算覆盖。

### HTML 高保真

按目标逻辑尺寸建立画布，宽高同比缩放。“1vp 对应画布 1 CSS px”仅是预览约定，不是物理像素换算。边框和说明文字不挤占逻辑画布；不能从预览大小或 vp 直接推算英寸。

## 4. 横向断点参考

以下为官方文档列出的窗口宽度参考区间。宽度必须大于 0，单位为 vp。

| 横向断点 | 窗口宽度 w |
|---|---|
| `xs` | `0 < w < 320` |
| `sm` | `320 ≤ w < 600` |
| `md` | `600 ≤ w < 840` |
| `lg` | `840 ≤ w < 1440` |
| `xl` | `w ≥ 1440` |

600 属于 md，840 属于 lg，1440 属于 xl；0 或无效尺寸是未初始化，不按 xs 处理。产品或工程可能调整阈值，不能把参考区间当作设备永久属性。

## 5. 纵向断点参考

本知识库中的纵向断点按高宽比 `r = h / w` 表示，不是按窗口高度的绝对 vp 值分类。

| 纵向断点 | 高宽比 r | 比例特征 |
|---|---|---|
| `sm` | `0 < r < 0.8` | 扁宽 |
| `md` | `0.8 ≤ r < 1.2` | 接近方形 |
| `lg` | `r ≥ 1.2` | 窄长 |

宽高必须来自同一对象、使用同一单位，任一无效时不计算。另设的短窗口高度阈值不能与本表的高宽比断点混用。

## 6. 窗口断点与容器断点

| 作用范围 | 用于什么 | 取值原则 |
|---|---|---|
| 窗口断点 | 页面整体布局、主导航、整页结构 | 当前应用窗口 |
| 容器断点 | 分栏内列表、局部卡片、嵌套区域 | 该组件实际获得的容器空间 |

明确断点的参考对象和阈值来源。系统窗口断点、容器断点、`GridRow` 配置及项目自定义值不保证相同，需按工程 SDK 核对，不能默认全部支持同样的 xl 区间。

## 7. 动态更新与框架边界

- 旋转、折展、缩放、分屏或密度变化后重新取值，不沿用初始化快照；覆盖任务涉及的全部区间，不能漏掉 xl。
- ArkUI、H5、RN、Flutter 使用各自的窗口或容器能力，不照搬 API；CSS px、RN 逻辑尺寸、Flutter logical pixels 与 vp 不能无依据等同，跨宿主比较需核对缩放与单位映射。

## 8. 数据性质和优先使用场景

| 数据性质 | 可以用于 | 不能冒充 |
|---|---|---|
| 官方规格或官方开发参考值 | 设备知识、参考预览、规划覆盖范围 | 当前运行窗口 |
| 运行态实测 | 对应机型、系统、显示缩放和窗口条件下的验证 | 所有设备和系统版本的通用参数 |
| 团队设计基线 | 无实测数据时的设计和高保真参考 | 官方硬件规格、已经验证的实际值 |

当前布局使用运行时数据，但不覆盖档案中的官方参考值；各自保留来源、日期和适用条件。断点不决定布局方案，选型见《一多适配总体原则》的布局调整说明。
