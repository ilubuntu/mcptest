## Overview 总体概述

用于确认“属于哪类设备、当前是哪种形态”，不决定列表列数、导航或分栏。具体型号的尺寸和能力查设备档案。

适用范围：本知识库中的直板机、折叠屏和平板设备。
核验日期：2026-11-02。

## 1. 设备类型与折叠类别

下列名称是知识库分类约定，不是 HarmonyOS 系统 API 枚举，也不要求修改测试工具已有的字段。

| 设备类型 | 含义 |
|---|---|
| `phone` | 直板手机，包含宽比例直板手机 |
| `foldable` | 折叠屏手机，另记折叠类别 |
| `tablet` | 平板 |

| 折叠类别 | 含义 |
|---|---|
| `standard` | 常规大折叠，单铰链、两个展开区域 |
| `wide` | 阔折叠，展开比例不同于常规大折叠 |
| `small` | 小折叠，通常沿机身纵向开合 |
| `trifold` | 三折叠，双铰链、三个展开区域 |

分类按产品资料确认，不按窗口宽度或名称猜测。宽比例直板机不是阔折叠；折叠设备合上仍是 `foldable`。不收录 PC/2in1；未知类型不能默认归为直板机。

## 2. 不要混用六类信息

| 信息 | 表达什么 | 示例 |
|---|---|---|
| 设备类型 | 产品属于哪类设备 | `foldable` |
| 折叠类别 | 折叠产品的结构或比例类别 | `trifold` |
| 使用形态 | 当前使用的屏幕区域组合 | F、N、M、LM、RM、G |
| 物理折叠状态 | 设备的折叠姿态 | `FoldStatus` 返回值 |
| 屏幕显示模式 | 系统报告的显示模式 | `FoldDisplayMode` 返回值 |
| 窗口状态 | 当前应用实际获得的显示空间 | 方向、窗口宽高、全屏、分屏或自由窗口 |

六类信息分别记录，不能相互替代：相同窗口尺寸不代表相同物理姿态。

## 3. 使用形态如何记录

按具体机型的官方名称逐行记录，不只分“折叠／展开”。

- F/N、LM/RM 即使同属单屏或双屏，也不能合并尺寸。
- 形态代码不是跨机型枚举，不从同系列其他型号补齐未收录形态。
- 单屏、双屏、三屏不是列表的一栏、两栏、三栏。
- 内外屏按实际结构记录，不假定所有折叠设备都有两块独立屏幕。

## 4. 物理折叠状态与显示模式

`FoldStatus` 表示物理状态，`FoldDisplayMode` 表示显示模式，接口与枚举按工程 SDK 核对。三折叠两处折叠区域的折叠、半折、展开可形成九种组合，不能与常用使用形态强行一一对应。

映射需注明机型、形态、物理状态、显示模式及依据；实测补充系统版本和采集条件。Mate XTs 的映射不能直接用于 Mate XT 2；没有依据时记为“未核验”。

## 5. 半折、悬停与设备能力

半折不等于支持悬停。例如官方明确 Mate XT 2 不支持悬停态，不能继承其他 Mate XT 系列的悬停方案。相机、手写笔、多窗等能力也需按机型和适用条件确认。

“不推荐使用”“未公开”“未核验”“不支持”分别表述，未知不能写成不支持。

## 6. 方向与窗口状态

方向用 `portrait / landscape`；需要区分反向时保留系统方向枚举，旋转枚举数字不能直接当角度。窗口另记全屏、分屏或自由窗口。

档案参考方向不是应用方向限制。相同旋转值在不同设备或形态下不一定表示同一方向；型号不明确时不能用系列资料替代。分类本身不扩大任务、高保真或测试范围。
