# ArkUI 平行视界不生效、页面配对错误与跨栏截断

## Overview 总体概述

平行视界未出现、右边显示错页、两栏相互覆盖，看起来都像“大屏布局问题”，但分别可能来自配置未生效、路由标识错误和内容仍按整窗计算。先确认当前确实进入系统平行视界，再处理具体原因；普通 Navigation Auto 产生的空右栏不属于同一分支。

## 问题现象与适用条件

- 部分宽屏形态能分栏，其他宽屏不出现。
- 主页或关联页不正确，详情无参数而白屏。
- 调整栏宽后图片、文字越界，右栏内容盖住左栏。
- 两边使用同一图片，但只在一侧显示。

适用于已明确采用 EasyGo 平行视界的 ArkTS 工程。应用自配置从 API 23 起支持；更新配置项必须匹配目标系统及 SDK。自由多窗不依赖该能力强行分栏，系统分屏支持也有单独版本与配置条件。

## 原因与判断依据

| 分支 | 具体核对 |
|---|---|
| 配置未生效 | entry 的 module 配置是否引用正确 profile，配置是否打进安装产物；设备专用配置是否覆盖 common；是否漏了方形宽屏分支 |
| 页面配错 | Router 使用 pages 中的路径，Navigation 使用目标页名称；全局 Navigation 的 id 与配置是否一致 |
| 关联页白屏 | relatedPage 是否依赖动态业务参数；关联页机制不能代传任意参数 |
| 内容越界 | 页面已只有一栏，但图片、断点或自绘内容还用整窗宽度；比例变化后仍保留旧坐标 |
| 单侧资源消失 | 是否把同一个 NodeController 或节点树实例挂到两个同时可见页面；共享地址与共享节点实例不同 |

## 解决方案

### 1. 让配置与真实路由对应

在 entry 的 `module.json5` 中，保留已有字段并增加模块级 `easyGo: "$profile:easy_go"`；profile 位于本模块 `resources/base/profile/easy_go.json`。Navigation 示例：

```json
{
  "common": {
    "displayModeOptions": {
      "wideWindowMode": "navigationSplit",
      "squareWindowMode": "navigationSplit",
      "navigationSplitOptions": {
        "homeNavigationId": "mainNavigation",
        "homePage": "navBar",
        "relatedPage": "CategoryPage",
        "enableReducedContainerSize": true
      }
    }
  }
}
```

`mainNavigation` 对应业务全局 Navigation 的 `.id()`。`navBar` 表示 Navigation 首页；主页是 NavDestination 时改用真实名称。CategoryPage 只是无需动态参数的示例；没有合适关联页时不要伪造一个详情页。

Router 工程改用 `routerSplit` 和 `routerSplitOptions`，页面写真实路径，不同时塞入两套 options。设备专用配置与 common 合并，同名字段由设备配置覆盖，应核对合并后真正生效的模式和页面参数。

### 2. 用所属页面尺寸约束内容

优先使用父容器分配的宽度，不按整屏硬除以二。需要兼容原整窗计算时，核对并使用 `enableReducedContainerSize` 的虚拟容器能力，不能开启后又重复缩小一次。

API 23 起可通过页面尺寸回调，例如 `onNavDestinationSizeChange` 或 `onRouterPageSizeChange`，更新所属页面的自绘区域。监听按页面生命周期成对注销，返回单栏时恢复新的页面尺寸。

对于手写 Row 双栏，左右栏应在同一个有界容器分配空间：一栏有合理宽度，另一栏取剩余宽度；不要让右栏 `position` 仍使用旧左栏宽度。浮层限定到所属栏，clip 不是修复跨栏约束的替代品。

### 3. 新配置与实例复用分别处理

API 26 起的 `mode`、`pagePairs`、`transPages`、拖拽比例、`drawableRectHook`、`enableInSplitScreen` 等不能复制给旧目标系统。导航模式固定主页，购物模式按路由栈推进，页面配对和过渡页字段应与模式对应；动态拖拽后以实际页宽为准。

左右页面分别创建、挂载和释放 UI 节点实例，业务数据与图片地址可以共享。不能通过重复 push 路由解决实例抢占。

## 修复后检查

检查长方形和方形宽屏、主页直达、连续跳转、返回、全屏页进出及支持的比例变化。确认真正进入分栏，页面配对正确，两侧无裁切和相互覆盖，退出后没有残留半宽尺寸；两个页面同显时资源不互相抢占。
