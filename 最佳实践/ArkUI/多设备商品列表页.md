## Overview 总体概述

页面由标题与搜索区、可滚动商品区、底部操作区组成。商品区按自身宽度切换列数，标题和底栏不参与滚动；图片不会跟整窗无限放大，搜索词和购物数量不因宽窄切换清空。本篇给出一份完整页面代码，不替换业务工程已有导航、数据服务和主题系统。

## 适用条件

- 原生 ArkTS/ArkUI、Stage 模型；本例以 API 20 为构建基线。
- 商品为同质卡片，允许宽屏并排展示；示例数据量较少，采用 Scroll + GridRow。大量分页数据应沿用工程已有的 List、Grid 或懒加载方案，不直接照搬全量 ForEach。
- 原设计不要求新增列表—详情分栏。页面本身不创建 Navigation，不根据手机、折叠屏或平板标签决定列数。

## 接入步骤与关键约束

1. 新建一个已注册的 ArkUI 页面，将下方代码作为该页面的完整内容。已有入口页只选一个 `@Entry`；嵌入现有组件时去掉本例 `@Entry`，保留宿主导航。
2. 用真实数据替换商品数组，保留稳定业务 ID、搜索和加入操作。系统应用图标仅作占位，换成业务图片时保留展示框与适当的 ImageFit。
3. GridRow 使用 ComponentSize，以商品区实际宽度决策。示例采用十二份栅格和 1/1/2/3/4 列；这组边界与列数是页面策略，不是设备标准，应结合卡片最小宽度调整。
4. 中间 Scroll 在根 Column 中占剩余高度，不能再给它的内容强设一屏高度。商品标题允许两行摘要，完整信息由真实业务详情入口提供；不擅自省略关键操作。

## 完整页面代码

```ts
interface ProductData {
  id: string;
  name: string;
  price: number;
}

@Entry
@Component
struct ProductListPractice {
  @State private query: string = '';
  @State private cartCount: number = 0;
  @State private currentBreakpoint: string = 'xs';
  private products: ProductData[] = [
    { id: 'p01', name: '便携保温杯', price: 69 },
    { id: 'p02', name: '旅行收纳包', price: 49 },
    { id: 'p03', name: '轻量运动背包', price: 139 },
    { id: 'p04', name: '桌面阅读灯', price: 129 },
    { id: 'p05', name: '无线充电底座', price: 99 },
    { id: 'p06', name: '可折叠手机支架', price: 39 }
  ];

  private visibleProducts(): ProductData[] {
    const keyword: string = this.query.trim();
    return this.products.filter((item: ProductData) =>
      item.name.includes(keyword));
  }

  @Builder
  private productCard(item: ProductData) {
    Column({ space: 8 }) {
      Image($r('sys.media.ohos_app_icon'))
        .width('100%')
        .height(120)
        .objectFit(ImageFit.Contain)
      Text(item.name)
        .fontSize('16fp')
        .width('100%')
        .maxLines(2)
        .textOverflow({ overflow: TextOverflow.Ellipsis })
      Row({ space: 8 }) {
        Text(`￥${item.price.toFixed(2)}`)
          .fontSize('16fp')
          .layoutWeight(1)
        Button('加入')
          .id(`product-add-${item.id}`)
          .onClick(() => {
            this.cartCount += 1;
          })
      }.width('100%')
    }
    .width('100%')
    .padding(12)
    .alignItems(HorizontalAlign.Start)
    .border({ width: 1, color: Color.Gray })
    .borderRadius(12)
  }

  build() {
    Column() {
      Column({ space: 8 }) {
        Text('商品列表')
          .fontSize('22fp')
          .fontWeight(FontWeight.Bold)
        TextInput({ placeholder: '搜索商品', text: this.query })
          .id('product-search')
          .onChange((value: string) => {
            this.query = value;
          })
        Text(`商品区断点：${this.currentBreakpoint}`)
          .fontSize('12fp')
      }
      .width('100%')
      .padding(16)
      .alignItems(HorizontalAlign.Start)

      Scroll() {
        Column() {
          if (this.visibleProducts().length === 0) {
            Text('没有匹配的商品')
              .width('100%')
              .padding(16)
          }
          GridRow({
            columns: { xs: 12, sm: 12, md: 12, lg: 12, xl: 12 },
            gutter: { x: 12, y: 12 },
            breakpoints: {
              value: ['320vp', '600vp', '840vp', '1440vp'],
              reference: BreakpointsReference.ComponentSize
            }
          }) {
            ForEach(this.visibleProducts(), (item: ProductData) => {
              GridCol({
                span: { xs: 12, sm: 12, md: 6, lg: 4, xl: 3 }
              }) {
                this.productCard(item)
              }
            }, (item: ProductData) => item.id)
          }
          .width('100%')
          .onBreakpointChange((value: string) => {
            this.currentBreakpoint = value;
          })
        }.width('100%')
      }
      .width('100%')
      .layoutWeight(1)
      .padding({ left: 16, right: 16, bottom: 12 })

      Row({ space: 12 }) {
        Text(`已加入 ${this.cartCount} 件`)
          .fontSize('16fp')
          .layoutWeight(1)
        Button('清空')
          .id('cart-clear')
          .onClick(() => {
            this.cartCount = 0;
          })
      }
      .width('100%')
      .padding(16)
    }
    .width('100%')
    .height('100%')
  }
}
```

## 接入时保留的边界

本例使用正常页面安全区，不开启全屏、不忽略系统安全区，也不再次手算导航条高度。沉浸式宿主需要沿用自己的避让机制，不能把本例 padding 当作系统安全区数值。已有组件 ID、路由和服务接口在真实工程中继续保留，不用本例 ID 覆盖它们。

固定 120vp 的图片框用于控制卡片占高，Contain 保留完整图片，出现合理背景留白不是缺陷；需要铺满裁切时应由业务确认。长列表重排后的精确阅读锚点、接口分页、结算和详情页不在本例中实现。
