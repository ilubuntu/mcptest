## Overview 总体概述

键盘弹起或窗口变短时，标题与提交区保留自己的空间，中间表单取得剩余高度并滚动。本篇给出输入、勾选、提交反馈、显式收起键盘和模式恢复的完整示例；不按固定手机屏高安排品牌区，也不通过叠加键盘高度反复抬高页面。

## 适用条件

- 原生 ArkTS/ArkUI、Stage 模型；本例以 API 20 为构建基线，使用 V1 状态管理与页面级键盘模式。
- 适用于已确认采用页面压缩避让的普通表单，不是要求所有输入页从 OFFSET 改为 RESIZE。这里的模式设置不适用于独立 Dialog、Popup 或半模态。
- 示例为一个独立注册页面。放入 Navigation、Tabs 或有缓存的宿主时，必须由已有可见性和窗口策略管理者接管模式交接，不复制多个竞争的模式所有者。

## 接入步骤与结构

1. 把下方完整代码放入已注册页面；已有入口或组件保持原导航结构，只移植需要的布局与状态逻辑。
2. 标题与底部操作区在滚动区之外，List 通过 `layoutWeight(1)` 占根 Column 的剩余高度；每个输入项按内容测量，不设置整屏百分比高度。
3. 页面出现时保存实际旧模式，再设置 RESIZE；隐藏或销毁时恢复，不硬编码恢复为 OFFSET。表单内容保存在稳定页面状态中，模式变化不重新创建数据。
4. 姓名和勾选只演示基础交互，真实工程保留原校验、接口、协议和反馈逻辑。提交动作不是后端保存的实现。

## 完整页面代码

```ts
import { KeyboardAvoidMode as PageKeyboardAvoidMode } from '@kit.ArkUI';

interface FieldData {
  id: string;
  label: string;
  placeholder: string;
}

@Entry
@Component
struct CompactFormPractice {
  @State private values: string[] = ['', '', '', '', '', ''];
  @State private agreed: boolean = false;
  @State private feedback: string = '';
  private previousMode: PageKeyboardAvoidMode | undefined = undefined;
  private fields: FieldData[] = [
    { id: 'name', label: '姓名', placeholder: '请输入姓名' },
    { id: 'phone', label: '联系电话', placeholder: '请输入联系电话' },
    { id: 'email', label: '邮箱', placeholder: '请输入邮箱' },
    { id: 'address', label: '联系地址', placeholder: '请输入联系地址' },
    { id: 'invoice', label: '发票抬头', placeholder: '请输入发票抬头' },
    { id: 'note', label: '备注', placeholder: '请输入备注' }
  ];

  onPageShow(): void {
    const ui = this.getUIContext();
    if (this.previousMode === undefined) {
      this.previousMode = ui.getKeyboardAvoidMode();
    }
    ui.setKeyboardAvoidMode(PageKeyboardAvoidMode.RESIZE);
  }

  private restoreMode(): void {
    if (this.previousMode !== undefined) {
      this.getUIContext().setKeyboardAvoidMode(this.previousMode);
      this.previousMode = undefined;
    }
  }

  onPageHide(): void {
    this.restoreMode();
  }

  aboutToDisappear(): void {
    this.restoreMode();
  }

  private dismissKeyboard(): void {
    this.getUIContext().getFocusController().clearFocus();
  }

  build() {
    Column() {
      Row({ space: 12 }) {
        Text('填写资料')
          .fontSize('22fp')
          .fontWeight(FontWeight.Bold)
          .layoutWeight(1)
        Button('收起键盘')
          .id('form-dismiss-keyboard')
          .onClick(() => {
            this.dismissKeyboard();
          })
      }
      .width('100%')
      .padding(16)

      List({ space: 16 }) {
        ForEach(this.fields, (field: FieldData, index: number) => {
          ListItem() {
            Column({ space: 6 }) {
              Text(field.label).fontSize('16fp')
              TextInput({
                placeholder: field.placeholder,
                text: this.values[index]
              })
                .id(`form-input-${field.id}`)
                .width('100%')
                .fontSize('16fp')
                .onChange((value: string) => {
                  this.values[index] = value;
                  this.feedback = '';
                })
            }
            .width('100%')
            .alignItems(HorizontalAlign.Start)
          }
        }, (field: FieldData) => field.id)

        ListItem() {
          Row({ space: 8 }) {
            Checkbox({ name: 'agreement' })
              .id('form-agreement')
              .select(this.agreed)
              .onChange((value: boolean) => {
                this.agreed = value;
              })
            Text('已阅读并同意本次资料提交说明')
              .fontSize('16fp')
              .layoutWeight(1)
          }.width('100%')
        }
      }
      .width('100%')
      .layoutWeight(1)
      .padding({ left: 16, right: 16, bottom: 12 })

      Row({ space: 12 }) {
        Text(this.feedback.length > 0 ? this.feedback : '填写姓名并勾选后可提交')
          .fontSize('14fp')
          .layoutWeight(1)
        Button('提交')
          .id('form-submit')
          .enabled(this.agreed && this.values[0].trim().length > 0)
          .onClick(() => {
            this.dismissKeyboard();
            this.feedback = '示例已接收输入，尚未调用后端';
          })
      }
      .width('100%')
      .padding(16)
    }
    .width('100%')
    .height('100%')
  }
}
```

## 接入时保留的边界

本例不忽略页面安全区、不调用窗口全屏接口，也不在 RESIZE 之外再按同一键盘高度缩一次根容器。既有页面已完成系统避让时不重复叠加 padding。List 视口获得剩余高度，不代表任意极端小窗都能放下固定头尾；若头尾本身超过可用高度，需经设计确认后改紧凑排列或让更多内容参与滚动。

模式读回值在不同 API 版本存在差异，本例不作为 API 20 以下工程的兼容实现。多窗口、页面隐藏但未销毁和连续进入退出时，仍应接入工程已有模式管理，避免旧页面恢复覆盖新页面。输入法收起后的焦点行为以实际输入会话和设备验证为准。
